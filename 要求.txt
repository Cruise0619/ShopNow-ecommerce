# Web大作业：电商平台开发任务书
## 一、项目概述
### 1. 项目名称
基于Web的电商平台（前后端分离架构）

### 2. 技术栈
- **前端**：Vue3 + Element Plus + Pinia（Vscode开发）
- **后端**：Node.js/Express（IDEA开发）
- **认证鉴权**：支持OAuth/Shiro实现权限控制
- **数据库**：关系型数据库（存储用户、商品、订单等核心数据）
- **进阶拓展**：Redis缓存、微服务架构、Docker容器化部署

### 3. 核心架构
前后端分离架构：
- 前端：客户端（用户端）+ 管理后台（管理员端）
- 后端：提供RESTful API接口，处理业务逻辑、数据交互
- 通信：前端通过接口调用后端服务，实现数据交互

---

## 二、开发环境与启动规范
### 1. 开发工具
- 前端项目：使用 **VS Code** 打开`frontend`文件夹开发
- 后端项目：使用 **IntelliJ IDEA** 打开`backend`文件夹开发
- 快捷方式：双击`ecommerce.code-workspace`可同时打开前后端项目

### 2. 启动命令
#### 后端（端口：3000）
```bash
cd backend
npm install      # 安装依赖（首次执行）
npm run seed     # 初始化数据库+种子数据（首次执行）
npm run dev      # 启动开发服务器
```

#### 前端（端口：5173）
```bash
cd frontend
npm install      # 安装依赖（首次执行）
npm run dev      # 启动开发服务器
```

### 3. 测试账号
- 管理员：用户名`admin`，密码`admin123`，访问地址：`http://localhost:5173/admin/login`
- 普通用户：用户名`user1`，密码`123456`，访问地址：`http://localhost:5173/login`

## 三、功能需求清单
### 第一部分：基本要求（必做）
#### 1. 客户端（普通用户端）
##### 1.1 商品模块
- 商品分类浏览：支持按分类筛选商品列表
- 商品详情页：展示商品图片、名称、价格、库存、参数、详情介绍
- 商品搜索：支持精准/模糊搜索，支持按价格、销量、新品排序
- 商品收藏：收藏/取消收藏、查看收藏列表
- 商品评价：查看评价、提交评价、上传评价图片

##### 1.2 购物车模块
- 添加商品：选择商品规格、数量加入购物车
- 购物车列表：展示商品图片、名称、单价、数量、小计金额
- 购物车操作：修改数量、删除商品、勾选商品、全选/反选
- 购物车结算：跳转至订单确认页面

##### 1.3 订单模块
- 订单确认：选择收货地址、展示商品清单、自动计算总价
- 订单提交：生成订单号、选择支付方式
- 订单支付：支持模拟支付/对接支付接口
- 我的订单：分类查看全部/待支付/待发货/待收货/已完成/已取消订单
- 订单操作：取消订单、确认收货、申请退款、查看物流

#### 2. 管理后台（管理员端）
##### 2.1 管理员认证
- 管理员登录：账号密码登录、权限验证
- 管理员退出登录
- 可选：角色管理（超级管理员/普通管理员+权限分配）

##### 2.2 数据看板
- 核心数据统计：总用户数、总订单数、总销售额、今日订单/销售额
- 数据图表：销量趋势、热销商品排行、订单状态统计

##### 2.3 用户管理
- 用户列表：查看所有注册用户信息
- 用户搜索：按账号、手机号、昵称搜索
- 用户操作：禁用/启用用户、查看用户详情

##### 2.4 商品管理
- 商品分类管理：新增、修改、删除、排序分类
- 商品列表：查看、搜索、筛选商品
- 商品新增：上传图片、填写商品基础信息与详情
- 商品编辑：修改信息、上下架、调整库存/价格
- 商品删除：支持逻辑删除/物理删除
- 评价管理：查看、删除违规评价

##### 2.5 订单管理
- 订单列表：查看所有订单，支持多条件筛选
- 订单详情：查看商品、地址、支付、状态信息
- 订单操作：发货、取消订单、处理退款、修改订单状态
- 订单导出：导出订单数据为Excel文件

##### 3.2 首页模块

##### 3.4 营销功能
- 商品规格选择（颜色、尺寸）
- 优惠券功能
- 秒杀/促销活动

##### 3.5 辅助功能
- 客服咨询（留言/在线聊天）

- 用户反馈提交

#### 4. 管理后台进阶功能
- 轮播/广告管理：增删改查、上传图片、排序
- 系统管理：公告管理、用户反馈管理与回复
- 管理员个人中心：修改密码、个人信息
- 高级功能：数据统计导出、商品批量导入/导出、权限分级管理

#### 5. 通用进阶要求
- 响应式布局：适配电脑、手机端
- 图片上传功能
- 全列表数据分页功能

1. **缓存优化**：集成Redis，缓存商品信息、用户会话，提升响应速度

## 五、核心业务流程
1. **用户购物流程**：注册/登录 → 浏览/搜索商品 → 加入购物车 → 结算下单 → 支付 → 收货/评价
2. **管理员管理流程**：登录后台 → 数据看板查看 → 管理用户/商品/订单 → 系统配置管理
